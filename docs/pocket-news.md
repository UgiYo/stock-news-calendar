# 口袋證券新聞來源與台美股區分

新聞來源新增口袋學堂的公開研究／市場文章，統一保存來源名稱「口袋證券」。接受口袋學堂、口袋證券與常見誤字口袋證卷的來源名稱，正式顯示為「口袋證券 · 台股」或「口袋證券 · 美股」。

## 取得方式

- Google News 股票查詢加入 `site:pocket.tw/school/report`。
- 另讀口袋官網前端使用的公開新聞索引：`https://www.pocket.tw/invest_news/api/invest_news/`，參數為 `page`、`category`、`keyword`。此來源補足 Google News 尚未索引的文章；不需要或傳送使用者登入憑證、AI Key。
- 台股／美股搜尋預覽均加入公開索引，Google News 暫時失敗時仍可提供口袋來源，並顯示來源警告。日常與手動 Actions 新聞蒐集也讀取此索引，沿用原有個股追蹤及日期範圍。
- 個股異動追查的日期區間亦納入口袋文章，仍保留「搜尋不保證完整」的原有覆蓋限制。
- 僅接受 `pocket.tw`、`www.pocket.tw` 上的 `/school/report/分類/文章編號/` 個別文章。公告、活動、開戶及索引頁不作新聞原文。

## 台美股比對

市場由追蹤股票識別碼決定：例如 `2330` 為台股，`US:MSFT`／`US:TSM` 為美股。文章需明確比對該股票的名稱或代號，再套用標題市場語境；不依網站主機或粗略分類代碼（如 `SB`）將全部文章視為同一市場。

同名台股與 ADR 特別區分：台積電（2330）的文章不因中文別名相同而匯入 `US:TSM`；台積電 ADR／TSM 的文章也不自動匯入 2330。聯電／UMC、日月光／ASX、友達／AUOTY 使用相同識別規則。同篇明確提及兩地上市代號的文章可分別連到兩個追蹤標的，並保留各自市場的新聞記錄。

## 刊登日期與去重

Google RSS 有完整發布時間時，沿用台股台灣日期、美股美東日期的換算。

官網索引僅提供 `YYYY-MM-DD` 的刊登日期，沒有可驗證的時間或時區。因此保存來源刊登日期，`published_at` 亦保持日期字串；不虛構午夜／中午作發布時間，也不推算美東前一天。當日視窗顯示「來源僅提供日期」。若同篇 RSS 同時提供時間，合併去重時保留 RSS 的精確時間／市場日期與官網原文網址。

官網與 RSS 重複文章會合併；不同股票的相同原文仍保持股票識別碼分開。原文網址可隨蒐集結果保存，後續只有 RSS 的更新不清除既有原文網址。不需新資料表或 migration。

## 公開正文與驗證

口袋網頁正文存放於 `InvestNewsContent` 的 `data-content` HTML 編碼欄位。Worker 全文讀取及 Python 摘要流程會先解碼此欄位，保留文章段落，排除網頁導航、客服區塊、樣式與腳本。付費內容標記仍會阻止全文摘要。

2026-10-14 以官網公開索引及實際台股／美股頁面做唯讀驗證：台積電台股、微軟美股文章均可取得正文；原文元件解析未混入客服文字。正式環境實際收錄量依目前追蹤股票、日期範圍與來源可用性而定，不以測試資料宣稱正式篇數。

部署沿用 GitHub Pages 前端與現有 Cloudflare Pages API；API 仍使用 `npm ci && node scripts/build_cloudflare_pages.mjs`。每日新聞及手動更新仍由現有 `news.yml`／`scripts/collect.py` 處理，沒有新增排程或秘密設定。

主要驗證：`npm test`、Python `test_pocket_news.py`／`test_us_collector.py`／`test_collect*.py`、前端與 Cloudflare API build。
