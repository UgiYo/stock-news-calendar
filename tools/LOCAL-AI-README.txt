股聞日曆｜本機 AI 工具（Windows）

1. 需已有 Python 3.8 以上，不需 pip 或其他套件。
2. 將 ZIP 完整解壓縮到一個資料夾，勿在 ZIP 裡直接執行。
3. 雙擊 start-local-ai.vbs：在背景啟動，不需命令視窗。
4. 自動開啟本機頁面，按「複製配對碼」。
5. 股聞日曆 → AI 設定 → 本機 Python，貼配對碼並確認配對。
6. 填公司 LiteLLM HTTPS Base URL、模型與 API Key，測試連線。
7. 按當日總結或單篇摘要即可使用。關閉本機瀏覽器分頁不會停止背景工具。
8. 停止工具：開 http://127.0.0.1:8765，按「停止背景工具」。重新啟動需重新配對。

若 Windows／公司政策禁止 VBS，可雙擊 start-local-ai.bat（這種模式需保留命令視窗）。
也可執行 py -3 local_ai_bridge.py --open。
工具不會自動安裝 Python、不新增開機啟動項目、不更動公司電腦政策。
瀏覽器可能要求允許本機網路存取。若政策禁止，直接用本機頁面貼新聞即可。
工具只能在使用網站的同一台電腦上執行，手機不能使用電腦的 127.0.0.1。
公司服務需可由此電腦連線（VPN／HTTPS 憑證）；公司服務不需設定 CORS。
公司 CA 可用 --ca-file company-ca.pem 指定，保持 TLS 驗證。

金鑰與新聞只經此電腦送到指定 AI 服務，不傳到本專案後端。
工具不保存 API Key、新聞、結果或請求日誌。網頁勾選記住才會保存於該瀏覽器。
配對碼是本機通行碼，不是公司 API Key，永不保存於網頁設定。

版本 3：網站單篇／多篇摘要先由工具讀取三家來源的文章內文，再送 AI。
付費牆、內容不足、來源拒絕或 Google 原文解析失敗會停止，不用標題替代。
更新：先在舊本機頁面按停止，再下載新版 ZIP 解壓縮啟動並重新配對。
