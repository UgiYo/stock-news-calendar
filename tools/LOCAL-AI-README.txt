股聞日曆｜本機 AI 工具（Windows）

1. 需已有 Python 3.8 以上，不需 pip 或其他套件。
2. 將 ZIP 完整解壓縮到一個資料夾，勿在 ZIP 裡直接執行。
3. 雙擊 start-local-ai.vbs：在背景啟動，不需命令視窗。
4. 自動開啟本機頁面，按「複製配對碼」。
5. 股聞日曆 → AI 設定 → 本機 Python，貼配對碼並確認配對。
6. 填公司 LiteLLM HTTPS Base URL、模型與 API Key，測試連線。
7. 按當日總結或單篇摘要即可使用。關閉本機瀏覽器分頁不會停止背景工具。
8. 停止工具：開 http://127.0.0.1:8765，按「停止背景工具」。重新啟動需重新配對。

若 Windows／公司政策禁止 VBS，可雙擊 start-local-ai.bat（這種模式需保留命令視窗）。
也可執行 py -3 local_ai_bridge.py --open。
工具不會自動安裝 Python、不新增開機啟動項目、不更動公司電腦政策。
瀏覽器可能要求允許本機網路存取。若政策禁止，直接用本機頁面貼新聞即可。
工具只能在使用網站的同一台電腦上執行，手機不能使用電腦的 127.0.0.1。
公司服務需可由此電腦連線（VPN／HTTPS 憑證）；公司服務不需設定 CORS。
公司 CA 可用 --ca-file company-ca.pem 指定，保持 TLS 驗證。

金鑰與新聞只經此電腦送到指定 AI 服務，不傳到本專案後端。
第 5 版本機背景工具將任務、逐字稿與成果存入使用者家目錄的 .stock-news-local-ai/results.sqlite3。
API Key 只留於 Python 記憶體，任務結束後釋放；不寫進任務資料庫或請求日誌。
網頁勾選記住設定時，Key 仍會保存於該瀏覽器；共用電腦請勿勾選。
配對碼是本機通行碼，不是公司 API Key，永不保存於網頁設定。

版本 3：網站單篇／多篇摘要先由工具讀取三家來源的文章內文，再送 AI。
付費牆、內容不足、來源拒絕或 Google 原文解析失敗會停止，不用標題替代。
更新：先在舊本機頁面按停止，再下載新版 ZIP 解壓縮啟動並重新配對。

第 5 版：公司背景任務（可選）
- 公司 LiteLLM 原本能瀏覽器直連者，可繼續直連，不需安裝本工具。
- 只有選擇 LiteLLM + 本機 Python 時，新聞摘要、一鍵 Podcast、逐字稿摘要才交由本機佇列處理。
- Key、逐字稿與摘要不傳 Cloudflare 或 GitHub Actions。公開新聞/節目來源仍需從原網站下載；只有指定 LiteLLM 收到 AI 請求。
- LiteLLM 閘道後方路由由公司管理，本工具不決定公司閘道是否使用外部模型。
- 排入成功後可關閉網頁；電腦不能關機或休眠，Python 必須保持運作。
- 重新開網頁後配對並套用設定，即可在成果中心查看；也可直接開本機首頁查看。
- 工具重啟會將未完成任務標示為中斷；輸入 Key 後可續做，保留成功轉錄段落。
- 本機背景從公開來源下載長音訊需 ffmpeg / ffprobe 可在 PATH 找到；工具不自動下載或安裝。
- 沒有 ffmpeg 時仍可貼上逐字稿摘要；匯入音訊的裝置轉錄仍需網頁開啟。
- --data-dir 可指定公司允許的本機儲存目錄，避免使用同步到外部雲端的資料夾。
- 可在成果中心或本機頁面取消/刪除；已送往 LiteLLM 的單次請求可能仍會完成，但結果不會重新寫回已刪任務。
- 本機成果屬於該作業系統使用者；持有本機配對碼即可讀取，請勿共用配對碼。

Podcast 財經整理：轉錄加入財經術語提示，摘要依原稿與節目資料整理本集總結、族群、標的、重要校正對照與待確認。保留原始逐字稿；文字上下文校正不代表已回聽音訊。不推測股號、不擅改數字與買賣方向。要在本機背景工具使用新版詞彙提示，請重新下載工具 ZIP。
